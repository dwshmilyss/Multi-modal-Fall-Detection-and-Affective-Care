## 🎯 新增功能

### 1. AlarmManager - 告警管理器

**位置**: `../deidao/dialogs.py` (第 399-495 行)

**核心功能**:
- ✅ 自动检测指标异常并记录告警

| 危险 (CRITICAL) | 🔴 红色 (#EF4444) | 心率过高、发热、电量不足等严重异常 |

## 🔧 技术实现

### 告警检测流程

```
数据更新 → 指标检查 → 状态判断 → 告警记录 → 声音播放 → 弹窗显示（仅危险）→ 列表更新
```

### 冷却机制

```python
# 同类告警 5 秒内不重复触发
if last_time and (now - last_time).total_seconds() < 5:
    return None  # 冷却期内，不重复告警
```

### 静音控制

```python
def play_alarm(self):
    if self.alarm_manager.is_muted:
        return  # 静音时不播放
    # ... 播放告警音
```

## 🚀 使用示例

### 1. 查看告警记录

打开健康大屏后，告警记录面板会实时显示最近的告警。

### 2. 静音/取消静音

点击"🔔 声音开启"按钮切换静音状态：
- 开启：异常时播放告警音
- 关闭：异常时不播放声音

### 3. 查看告警统计

点击"📈 告警统计"按钮查看详细统计报告。

### 4. 清空记录

点击"🗑️ 清空记录"按钮清空所有告警历史。

## 📊 告警阈值

| 指标 | 正常范围 | 警告阈值 | 危险阈值 |
|------|----------|----------|----------|
| 心率 | 60-100 bpm | - | <60 或 >100 |
| 血氧 | ≥95% | <95% | - |
| 收缩压 | 90-140 mmHg | - | <90 或 >140 |
| 体温 | ≤37.5℃ | - | >37.5℃ |
| 电量 | ≥20% | - | <20% |
